## Selected projects

### 1. Predictive modeling and decision systems

**[Paywall Conversion Prediction — Estadão Case](https://github.com/Brunoborges95/Estadao_case_ds_2026)**

A machine learning case focused on predicting subscription conversion when a paywall is displayed.

* Compared Logistic Regression and CatBoost.
* Used chronological validation and metrics suitable for imbalanced classification.
* Investigated target leakage and excluded a feature containing information unavailable at prediction time.
* Translated model findings into recommendations for paywall strategy.

**[Offer Recommendation and Expected Return](https://github.com/Brunoborges95/Ifood_Sistema-de-Distribuicao-de-Ofertas_2025)**

A personalized offer allocation system that estimates the probability of offer completion and combines it with expected transaction value to rank customer–offer opportunities.

* Predictive modeling for offer conversion.
* Expected-return calculation to support decision-making.
* Personalized offer selection based on customer behavior.

**[BEES — Order Days Prediction](https://github.com/Brunoborges95/BEES-Challenge_2024)**

A forecasting problem focused on predicting the remaining number of days on which a customer will place orders during a month.

* Uses historical transactions and partial current-month information.
* Explores customer-level behavioral patterns and temporal features.
* Addresses practical prediction constraints, including customers with no observed orders in the current period.

**[End-to-End Fraud Detection](https://github.com/Brunoborges95/Mercado_Livre_E2E_DS_Fraud_Detection_2024)**

An end-to-end fraud detection workflow covering exploratory analysis, model development, evaluation, and deployment components.

* Logistic Regression, XGBoost, and CatBoost.
* Probability calibration and evaluation using ROC, KS, lift, and profit-oriented metrics.
* MLflow and ZenML for experiment tracking and pipeline organization.
* AWS deployment components.

### 2. Mathematical optimization and simulation

**[Portfolio Optimization with CVaR](https://github.com/Brunoborges95/portfolio_eficiente)**

A portfolio optimization application built with Streamlit, combining financial risk measures with mathematical optimization.

* Conditional Value at Risk (CVaR) and Value at Risk (VaR).
* Linear programming for portfolio allocation.
* Historical backtesting and interactive portfolio analysis.

**[World Cup 2026 — Dixon–Coles and Monte Carlo Simulation](https://github.com/Brunoborges95/WorldCup2026_Dashboard_and_Prediction)**

A football forecasting project combining probabilistic score modeling with tournament simulation.

* Dixon–Coles model for match-score probabilities.
* Parameter estimation using historical matches.
* Monte Carlo simulation of the tournament.
* Interactive dashboard and explicit discussion of model assumptions and limitations.

### 3. Recommendation systems and Generative AI

**[LLM with Retrieval-Augmented Generation](https://github.com/Brunoborges95/LLM-RAG)**

A conversational application that lets users select books and ask questions about them, exploring how retrieved context can support an LLM-based experience.

**[App Recommendation System — LightFM](https://github.com/Brunoborges95/Data-Science-Projects/tree/main/user-app-recommender)**

A recommendation engine based on hybrid collaborative filtering using LightFM and WARP loss.

The project explores personalized app recommendations based on user–item interaction patterns.
